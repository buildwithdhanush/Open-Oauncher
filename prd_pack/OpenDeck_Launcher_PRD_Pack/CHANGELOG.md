# Changelog

## 1.1.0 — 2026-11-02

- Re-audited the original APKM's resource inventory and exported asset catalogue.
- Added explicit requirements for media controls, photo slideshows, animated images, RSS/news reader, contacts grid/list, notification panel, toolbox, device status/gauges, share intents, grouping, and depth effects.
- Added permission/API constraints for notification and media-session access, public system APIs, RSS parsing, URI grants, and memory-safe animated media.
- Clarified that P2 features are optional to enable but remain part of the complete final product.
- Expanded acceptance criteria and tests; corrected the agent handoff checklist.
- No reference app code, DEX methods, serialized assets, brand artwork, or proprietary formats were copied.
- Method-level DEX decompilation and runtime observation remain outstanding because JADX/Apktool/REA tools were not available in the current environment.
